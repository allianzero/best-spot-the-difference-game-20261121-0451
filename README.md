Twin Lanterns is a spot-the-difference game in the browser: three original hand-drawn scenes — a sunny cottage garden, a harbour at dusk, a night market — each shown as two near-identical pictures side by side with 7 differences to find before the timer runs out. Click a difference in either picture to ring it on both, build a streak for combo points, spend a hint when you are stuck, and chase the best score across all three scenes. Every picture, every sound and every animation is drawn and synthesised in code: no image or audio files, no libraries, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click a scene (or press 1–3) to start. H spends a hint, M toggles sound, R restarts the scene, Esc returns to the menu.
